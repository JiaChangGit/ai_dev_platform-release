# AI Dev Platform v1.5.0 — 2026-08-24

## 版本摘要

第一個正式 Release 將平台精簡為可驗證的自有核心，保留任務流程、治理規則、初始化與發行工具，並以 GitHub Actions、SPDX SBOM 與 keyless Sigstore attestation 建立可重現的發布鏈。

## 新功能與修正

- 新增精簡且完整驗證的 Android、SSD PCIe 韌體與虛構規格範例。
- 合併重複的入門、架構、repository、CI/CD 與 release 文件，移除失效引用。
- 正式建置會產生 ZIP、SHA-256、SPDX 2.3 SBOM 與 SLSA v1 provenance，並固定到 source tag、commit、workflow 與 CI run。
- `release-build` 與 `release-promotion` 使用不同人的 GitHub Environment 人工核准關卡。

## 破壞性變更

- 移除約 1.1 GB 的 vendored OpenAI Cookbook、第三方 skills、subtree 同步、skill routing／audit、provider model 清單與 optional pack 機制。
- 依賴上述 vendored 內容或 optional pack CLI 的既有使用者，需要改由各工具的 plugin／skill 安裝機制管理相依內容。

## 升級步驟

1. 下載版本化 ZIP 與 SHA-256，執行 `sha256sum -c ai-dev-platform-1.5.0.zip.sha256`。
2. 執行 `gh attestation verify ai-dev-platform-1.5.0.zip -R JiaChangGit/ai_dev_platform-cicd-platform`，確認來源為 `v1.5.0` 與 commit `d03406dc783e220d48670977d587e522b0029a1a`。
3. 使用套件內的 `scripts/install_platform.py` 安裝或更新唯讀平台包；先前的 optional pack 參數不再支援。

## 已知問題

- GitLab Free 僅作為手動單向公開鏡像，GitHub 仍是 canonical source 與正式發布閘門。
- 本版本未內含第三方 Cookbook／skills；需要時必須透過對應工具的 plugin／skill 管理機制另行安裝。
