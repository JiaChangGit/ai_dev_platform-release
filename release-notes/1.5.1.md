# AI Dev Platform v1.5.1 — 2026-08-25

## 版本摘要

本版補齊可驗證的建立、更新與發行教學，並把 SSD PCIe 韌體 trace、Android App 與規格閱讀靜態手冊三份案例整理為可執行、可測試且明列邊界的流程。平台安裝器在保留舊版時會回報完整 backup 路徑。

## 新功能與修正

- 新增工作區架構、開發流程、資料流與 release 時序圖，以及文件聲明與證據對照表。
- 補齊全新產品建立、既有 dev project 更新、原子 commits、PR、required checks 與獨立審查的實際命令。
- 擴充 SSD host 模擬的 debug／trace 教學，明列 controller SDK、DMA、queue、ISR、燒錄與硬體驗證未實作。
- Android 範例固定 AGP 9.2.0、Gradle 9.4.1、JDK 17 與 SDK 36；release-build 已執行 build、JVM tests 與 Android lint。
- 規格案例新增來源 revision 登記、REQ ID 集合驗證，以及拒絕 script／外部資源的靜態 HTML 檢查。
- 更新產品初始化器的 GitHub Actions 完整 commit SHA pins，並統一 lint、test、build 順序。
- promotion 會把 candidate 標題與內容改成正式 Release，並連結同版 Release Note 與 evidence。
- `install_platform.py --keep-backup` 會輸出上一版平台的完整保留路徑，方便精確回復。

## 破壞性變更

無。產品仍使用 `platformVersionPolicy: always-current` 讀取平行的唯讀平台；既有產品的 CI、Gradle、Makefile 與原始碼不會被平台更新自動改寫。

## 升級步驟

1. 確認 GitHub Release 的 `isDraft=false` 且 `isPrerelease=false`；promotion 完成前不得安裝 candidate。
2. 下載六份版本化材料，驗證 ZIP、SBOM、provenance 三份 checksum。
3. 執行 `gh attestation verify ai-dev-platform-1.5.1.zip -R JiaChangGit/ai_dev_platform-cicd-platform`，核對 source tag、commit、workflow 與 run。
4. 使用目前穩定版的 `scripts/install_platform.py` 先執行 `--dry-run`，正式更新時加上 `--keep-backup` 並保存輸出的完整 backup 路徑。
5. 執行 consumer self-check、workspace audit，以及每個產品自己的 lint、test、build、package；需要採用新版 CI skeleton 時另開產品 PR。

## 已知問題

- GitLab 公開鏡像尚未建立；GitHub 仍是 canonical source 與正式發布閘門。
- SSD 案例是 C11 host 模擬，沒有真實 NVMe command、PCIe link、DMA、queue、ISR、cross compiler 或可燒錄 image。
- Android 成品是 debug APK，未涵蓋正式 keystore、裝置矩陣與 Play Console 發布。
- 規格案例使用虛構規格；validator 只能檢查追溯與靜態 HTML 邊界，不能證明真實 PCIe／NVMe 條文解讀正確或有散布授權。
